# Kılıç Satınalma eklentisi

**Kılıç Satınalma 1.1.5**, geliştirici **Ozan Beşinci**. Bağımsız kararlı **guncelleyici 2.3.0** ve mevcut **teklif-degerlendirme 4.0.5** içerir.

Güncelleyici Windows program sürümlerini ve isteğe bağlı DuckDB PDF eklentisini kontrol eder; yalnız açık seçim/onay verilen planı uygular. Teklif skill’inin sürümünü kontrol etmez veya güncellemez.

Teklif dosyaları önceki yayınla birebir korunur. Kılıç ikonu, marketplace yolu ve plugin kimliği aynıdır. Güncelleyici kaynak/test sınırları kendi BUILD.json ve TEST_RAPORU.md dosyalarında açık tutulur.
