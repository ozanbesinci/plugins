# Teklif sayisina gore modlar - v4 business rules retained

Track independent suppliers separately from comparable options. Revisions do not increase competition; alternatives from one supplier are not independent observations.

## N=0
Do not start offer comparison. Show inventory. If a specification exists, requirement extraction and an RFQ/RFI checklist may still be produced.

## N=1
Do not produce comparative score/rank or pretend market competition exists. Show `TEK TEKLIF - REKABET YOK`. Still run scope, hard gates, cost bridge, commercial/contract, supplier qualification and risk. Price reasonableness needs an external or historical reference; if no valid reference exists, state that price reasonableness could not be evaluated. Produce negotiation agenda and, when relevant, a second-source recommendation.

## N=2
Do not use median/deviation as market statistics. Produce direct A/B differences. If no independent reference quantity exists, use the two supplier quantities as separate scenarios rather than inventing an average. Comparative convergence/anomalous-price tests that need N>=3 do not run. Scoring may run if both offers are eligible and comparable; a top-score relative gap below 5% is a close-score warning, not statistical equivalence.

## N=3..6
Use the full method when other gates permit it.

## N>=7
Apply hard gates and decision-relevant comparable cost to all suppliers before shortlisting. Deep review may focus on a documented 4-5 option shortlist plus any option whose uncertainty could put it into the shortlist. Keep non-shortlisted options visible with reason. The user may change the shortlist.

Recompute the mode after exclusions.
